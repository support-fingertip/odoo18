                            Quick Reference Guide

╔══════════════════════════════════════════════════════════════════════════╗
║                         INSTALLATION METHODS                             ║
╚══════════════════════════════════════════════════════════════════════════╝

Choose ONE of the following methods:


┌──────────────────────────────────────────────────────────────────────────┐
│ METHOD 1: VIA ODOO UI (Easiest - Recommended for Most Users)            │
└──────────────────────────────────────────────────────────────────────────┘

Step 1: Login to Odoo
   → Open browser: http://your-odoo-url:8069
   → Enter admin username and password

Step 2: Go to Apps
   → Click "Apps" in the top menu bar
   → (You should see a list of available apps)

Step 3: Update Apps List
   → Click the "⋮" (three dots) or "Update Apps List" button
   → Click "Update" in the confirmation dialog
   → Wait a few seconds for the update to complete

Step 4: Search for Module
   → In the search box, type: "Project Ticket Management"
   → Or type: "ticket"
   → Remove any default filters if needed (click ❌ on filter chips)

Step 5: Install
   → You'll see: "Project Ticket Management" module card
   → Click the "Install" button
   → Wait 5-10 seconds

Step 6: Verify
   → Look for new menu: "QA & Testing" in main menu bar
   → Click it to see: Test Plans, Test Scenarios, Test Cases, Tickets

✅ DONE! Module is installed and ready to use!


┌──────────────────────────────────────────────────────────────────────────┐
│ METHOD 2: VIA COMMAND LINE (For Developers/System Admins)               │
└──────────────────────────────────────────────────────────────────────────┘

Step 1: Open Terminal/Command Prompt

Step 2: Navigate to Odoo Directory
   $ cd /path/to/odoo18

Step 3: Run Installation Command
   $ ./odoo-bin -c odoo.conf -d your_database -i project_ticket_mgmt --stop-after-init

   Replace:
   - "odoo.conf" with your config file path
   - "your_database" with your database name

Step 4: Start Odoo Server
   $ ./odoo-bin -c odoo.conf

Step 5: Access Odoo
   → Open browser: http://localhost:8069
   → Login
   → Look for "QA & Testing" menu

✅ DONE!


┌──────────────────────────────────────────────────────────────────────────┐
│ METHOD 3: DOCKER (If Using Odoo in Docker Container)                    │
└──────────────────────────────────────────────────────────────────────────┘

Step 1: Copy Module (if not already in volume)
   $ docker cp project_ticket_mgmt your-container:/mnt/extra-addons/

Step 2: Install Module
   $ docker exec your-container ./odoo-bin -d DB -i project_ticket_mgmt --stop-after-init

Step 3: Restart Container (if needed)
   $ docker-compose restart odoo

Step 4: Access via browser and verify

✅ DONE!

╔══════════════════════════════════════════════════════════════════════════╗
║                    POST-INSTALLATION SETUP                               ║
╚══════════════════════════════════════════════════════════════════════════╝

After installing, do these quick steps:

1. ASSIGN USER GROUPS (Required)
   ─────────────────────────────
   Settings → Users & Companies → Users → Select User → Edit
   
   Scroll to "Ticket Management" and assign:
   - QA Manager → For QA team leads (full access)
   - Test Engineer → For QA testers (can create tests/tickets)
   - Developer → For developers (can view/update assigned tickets)

2. CREATE FIRST PROJECT (If you don't have one)
   ────────────────────────────────────────────
   Project → Create → Enter project name → Save

3. CREATE FIRST TEST PLAN
   ────────────────────────
   QA & Testing → Test Plans → Create
   - Select Project (required)
   - Fill Test Objectives
   - Save
   - Check: ID should be "TP-0001"

4. CREATE FIRST TICKET
   ───────────────────
   QA & Testing → Tickets → Create (in Kanban view)
   - Enter Title: "Test Bug"
   - Select Project
   - Save
   - Check: ID should be "TK-0001"

╔══════════════════════════════════════════════════════════════════════════╗
║                     TROUBLESHOOTING                                      ║
╚══════════════════════════════════════════════════════════════════════════╝

Problem: Module not appearing in Apps list
Solution: Make sure you clicked "Update Apps List" and waited for it to finish

Problem: "Module not found" error
Solution: Check that module is in correct location:
          ls /path/to/odoo18/addons/project_ticket_mgmt/

Problem: Can't see "QA & Testing" menu after install
Solution: 1. Refresh browser page (Ctrl+F5)
          2. Check user has appropriate group assigned
          3. Try logging out and back in

Problem: Access denied errors
Solution: Assign user to "QA Manager" group in Settings → Users

Problem: Sequences not generating (IDs stay at "/")
Solution: Restart Odoo or reinstall module:
          ./odoo-bin -d DB -u project_ticket_mgmt --stop-after-init
